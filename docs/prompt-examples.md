# Prompt examples for GPT Image 2

These prompts are written for testing the GPT Image 2 API through APIDot. They are starting points for product teams, not guaranteed outputs. Adjust brand names, subject details, source URLs, and safety rules before production use.

## 1. Readable product hero

A premium ecommerce hero image of a brushed-steel espresso machine on a clean white studio background, readable engraved label 'APIDOT PRO', realistic reflections, soft shadow, commercial photography.

## 2. UI mockup visual

A realistic phone mockup showing a clean analytics dashboard with legible labels, compact charts, tidy cards, neutral background, product launch presentation style.

## 3. Ad poster with text

A modern poster for a productivity app, large readable headline 'Ship Faster', secondary text 'Async AI media workflows', clean grid layout, realistic paper texture.

## 4. Reference edit

Keep the object shape and logo from the source image, replace the background with a bright studio sweep, add a natural contact shadow, and make it suitable for a product catalog.

## 5. Localized campaign asset

A square social ad for a travel camera with readable bilingual packaging text, warm daylight, realistic lens glass, clean negative space for copy.

## 6. Infographic style

A polished infographic explaining a 4-step API workflow with readable labels: submit, task_id, poll, result URL; simple icons, crisp layout, white background.

## Production prompt notes

- Store prompt versions together with task_id, model, user/job owner, and request payload.
- Keep source media URLs reachable long enough for APIDot to fetch them.
- Be explicit about composition, typography, material, lighting, output size, and reference-image constraints.
- Do not log prompts or source media URLs if they may contain private customer data.
